# Sacred Audio Directory for Shree Baba Sidhnath Mandir

Place your high-quality devotional audio tracks in this folder (`public/audio/`).
The website audio player automatically looks for these files:

| Track Name | Expected File Path | Devotional Purpose |
| :--- | :--- | :--- |
| **Hanuman Chalisa** | `/audio/hanuman-chalisa.mp3` | Sacred chanting of Goswami Tulsidas's Hanuman Chalisa. |
| **Om Namah Shivaya** | `/audio/om-namah-shivaya.mp3` | Eternal Panchakshari Shiva mantra meditation. |
| **Temple Bells & Shankh** | `/audio/temple-bells.mp3` | Authentic Ashta-dhatu bells and Shankhadhwani resonance. |
| **Flute Meditation** | `/audio/flute-meditation.mp3` | Classical bansuri flute in Raga Bhairav / Yaman. |
| **Rain + Temple Bells** | `/audio/rain-temple-bells.mp3` | Soothing monsoon rain with distant temple chimes. |
| **Morning Mangala Aarti** | `/audio/morning-aarti.mp3` | Sacred dawn Mangala Aarti chants. |
| **Evening Sandhya Maha Aarti**| `/audio/evening-aarti.mp3` | Grand evening Aarti with bells and camphor lamps. |

> **Note**: If a file is not yet placed in this folder, the website's built-in Web Audio API Spiritual Sound Synthesizer will automatically generate authentic acoustic harmonies, bansuri flute drones, and bell overtones so there is never silence!
